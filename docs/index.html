restoric

Browse and restore files from a restic repository by time, anchored on a folder. Like Time Machine, in your terminal.

GitHubReleasesIssues

Why

You know the file was in ~/dev/project last Tuesday. With plain restic you mount the repository or list snapshots and guess which one has it. restoric starts from the folder instead and steps through the moments it changed.

What it does

  • Folder first. Open a folder and scrub through time. It stops only at snapshots where that folder changed.
  • See the change. Preview any version, or diff it against disk or the previous version.
  • Restore like copy and paste. y yank, p restore next to the original, P overwrite after it tells you what differs. :undo puts it back.
  • Read-only. Never writes to the repository. No FUSE, no mount.
  • Any backend. Built on rustic_core: local, sftp, REST, rclone, S3, B2, Azure and more.
  • Looks like yazi. Vim keys, mouse support, Nerd Font icons, themeable.

Install

brew install borje/tap/restoric

Or, with Rust 1.91+:

cargo install --locked restoric

Release binaries for Linux (x86_64, aarch64, glibc or static musl), Debian/Ubuntu (.deb) and macOS are on the releases page.

Try it

restoric demo     # no repository needed
export RESTIC_REPOSITORY=sftp:nas:/backup/restic
export RESTIC_PASSWORD_COMMAND="pass show restic"
restoric                 # the current folder
restoric ~/dev/project   # or any folder in your backups

Keys

j k h lMove, parent / open
H LOlder / newer change in this folder
⇥ dPreview content or diff / full-screen diff
y p PYank, restore next to it, overwrite
s / fSearch all snapshots, search, filter
