restoric

A clickable mockup of the TUI using an invented sample repo. Stay in one folder and step back through time. The timeline only stops at snapshots where something inside that folder changed. Keys follow vim, and arrow keys work too.

Terminal width

  
Click the terminal to use the keyboard.Everything is clickable too: timeline dots, rows, breadcrumbs, zoom, dialog options.


  

    

      
Try this

      
    
        
  1. Press H (or ←) a few times. You step through versions of src/ and skip snapshots where it didn't change.
    2. 
        
  2. main.go is selected, so the second timeline row shows only its changes. Press { or } to jump between them.
    3. 
        
  3. Type :find legacy and press ⏎ twice. You land on the last snapshot that still had the deleted file.
    4. 
        
  4. Press v on a file for its versions, d to diff, and ]c to step through changes.
    5. 
        
  5. Press zi to zoom the timeline, or :sep 1 to jump to a date. Put a number before a motion: 3H.
    6. 
        
  6. Switch to 80 columns. The versions pane folds away.
