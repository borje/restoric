restoric

A clickable mockup of the TUI using an invented sample repo, styled after yazi. Stay in one folder and step back through time. The timeline only stops at snapshots where something inside that folder changed. The right column previews the selected file as it was in that snapshot.

Terminal width

  
Click the terminal to use the keyboard.Icons stand in for Nerd Font glyphs. Everything is clickable.


  

    

      
Try this

      
    
        
  1. Press H a few times. You step through versions of src/, and the preview marks lines that changed in each version with +.
    2. 
        
  2. Press Tab to switch the preview to a diff against disk. J K scroll it.
    3. 
        
  3. Press Space on two files, then y to yank them and p to restore them next to the originals. P overwrites instead.
    4. 
        
  4. Press z or c and wait: a popup lists what can follow.
    5. 
        
  5. Type s legacy ⏎ ⏎ to find a deleted file and jump to its last snapshot.
    6. 
        
  6. Press f to filter the listing, ⏎ on a file for all its versions, d for a full-screen diff.
    7.
